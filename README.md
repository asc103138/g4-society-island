# 康軒四上 社會島・家鄉時空英雄傳 3D 沉浸 RPG 冒險

> 專為國小四年級學童設計之社會科期中評量 3D 沉浸式互動複習網頁。以 Three.js 低多邊形（Low-Poly）玩具微縮模型風格打造自然島嶼地景，融合 RPG 冒險等級、實境動手小實驗、多題型闖關題庫與榮譽結業證書。

🌐 **線上即時體驗網址**：https://asc103138.github.io/g4-society-island/

---

## 🏝️ 三大自然島群與十大核心站點

### 島群 1：家鄉環境島（第一單元：家鄉的環境）
1. **家鄉地圖站**：地圖四要素（圖名、方向標、圖例、比例尺）實作組裝工作台。
2. **電子地圖塔**：衛星空照、地圖圖層與生活導航應用。
3. **平原與盆地**：宜蘭平原、嘉南平原（水稻、魚塭）與臺中盆地、臺北盆地地形特徵。
4. **丘陵與山地**：大肚臺地（頂部平坦邊緣陡峭）、苗栗丘陵茶園與中央山脈高山。
5. **氣候觀測站**：氣象百葉箱、雨量長條柱狀圖與氣溫折線圖解讀。
6. **水庫與水資源**：夏雨冬乾、河川短促蓄水水庫與海廢減塑回合戰。

### 島群 2：傳統住屋島（第二單元：家鄉的傳統生活）
7. **紅磚三合院**：正身正廳供奉神明祖先、長幼有序（左尊右卑左護龍住長輩）與大灶柴灰悶烤地瓜。
8. **石板屋與地下屋聚落**：排灣/魯凱族石板屋（石縫排煙防蟲會呼吸）與達悟族半地下屋（避強風抗颱）。

### 島群 3：器物生活島（第二單元：家鄉的傳統生活）
9. **古早器物市集**：阿美族/鄒族竹編魚筌（倒鬚漏斗放小魚永續捕魚）與木杵石臼搗小米麻糬。
10. **淨灘海岸**：海洋廢棄物調查（第一名寶特瓶）與自備水壺源頭減塑永續生活。

## 🎮 RPG 冒險系統亮點

- **頂部 HUD 狀態列**：即時 HP 生命值、MP 魔力條、金幣（G）、冒險稱號（Lv.1~10）與探索星星（0~30 ★）。
- **🎒 冒險者背包**：可使用「炭火悶烤地瓜」回復 40 HP、「丘陵高山烏龍茶」回復 25 MP。
- **🎖️ 探索徽章冊**：通關各站小實驗與考核題，自動點亮專屬徽章。
- **📖 社會生活小辭典**：隨時查閱單元關鍵概念與易錯迷思提醒。
- **📋 教師教材審查台**：內建教育部標準國字與三階漏斗審查報告。
- **🏆 結業榮譽獎狀**：輸入班級、座號與姓名，即時於 Canvas 上繪製專屬金色證書並支援一鍵下載 PNG。

## 🛠️ 技術規格

- **3D 引擎**：Three.js (WebGL, OrbitControls, PCFSoftShadowMap)
- **前端技術**：HTML5, CSS3 (Modern Responsive Flexbox/Grid, Glassmorphism), ES Modules
- **音效引擎**：Web Audio API 原生程序化音效合成（無需外連音檔）
- **繪圖處理**：HTML5 Canvas 2D 動態插圖與獎狀合成生成
- **相容性**：支援 Chrome、Edge、Safari、Firefox 及平板/行動裝置全螢幕操作
