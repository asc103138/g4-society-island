# 康軒四上 社會島・家鄉時空英雄傳 3D 沉浸 RPG 冒險

> 專為國小四年級學童設計之社會科 3D 沉浸式互動複習網頁。以 Three.js 低多邊形（Low-Poly）玩具微縮模型風格打造自然島嶼地景，融合 RPG 冒險等級、實境動手小實驗、多題型闖關題庫與榮譽結業證書。

- **第一、二單元地圖（15 站 + 方向標海龜導覽）**：https://asc103138.github.io/g4-society-island/
- **第三單元獨立地圖（8 站雙島 + 海上巨型祖靈彩虹橋導覽）**：https://asc103138.github.io/g4-society-island/unit3/

## 🏝️ 第一、二單元地圖（`index.html`，共 15 大站點 / 45 ★）

### 島群 1：家鄉環境島（第一單元：家鄉的環境，第 1～8 站）
1. **家鄉地圖站**：地圖四要素（圖名、方向標、圖例、比例尺）實作組裝工作台。
2. **電子地圖塔**：衛星空照、地圖圖層與生活導航應用。
3. **平原與盆地**：宜蘭平原、嘉南平原（水稻、魚塭）與臺中盆地、臺北盆地地形特徵。
4. **大肚台地**：頂部平坦、邊緣陡峭，紅土旱作甘藷與工業區。
5. **石碇丘陵**：起伏平緩、排水良好之梯田茶園與柑橘果園。
6. **中央山脈高山**：高聳山林與自然生態保育。
7. **氣候觀測站**：氣象百葉箱、雨量長條圖與氣溫折線圖解讀。
8. **水庫與水資源**：夏雨冬乾、河川坡陡流急、水庫蓄水發電與節水行動。

### 島群 2：傳統住屋島（第二單元：家鄉的傳統生活，第 9～13 站）
9. **紅磚三合院大宅**：正身正廳供奉神明祖先、長幼有序（左尊右卑，左護龍前端設大灶廚房）與牛棚農具間配置。
10. **竹管厝與土埆厝工坊**：就地取材竹篾夾泥牆與稻草攪泥土埆磚。
11. **排灣與魯凱族石板屋**：頁岩交錯疊砌冬暖夏涼，石縫排煙防蟲防腐會呼吸。
12. **達悟族蘭嶼地下屋**：順應坡地深掘主屋避強風抗颱、高腳涼台吹風看海。
13. **泰雅族武荖坑木屋**：高床架空防潮防蛇蟲、原木疊牆與黃藤綁紮工藝。

### 島群 3：器物海灘島（第二單元：家鄉的傳統生活，第 14～15 站）
14. **古早器物市集**：竹藤魚筌（留縫隙放小魚永續捕魚）、木杵石臼與通風防蟲菜櫥。
15. **淨灘海岸**：海洋廢棄物調查（塑膠製品最多）與源頭減量減塑行動。
- **海上看門獸導覽**：**方向標海龜**（飄浮於東南方海面，龜殼立指北標、身旁漂浮竹編魚筌）。

## 🌈 第三單元獨立地圖（`unit3/index.html` & `unit3.html`，共 8 大站點 / 24 ★）

### 島群 1：傳統信仰島（第三單元 第 1 課：家鄉的傳統信仰，第 1～4 關）
1. **原住民族歲時祭儀站**：阿美族豐年祭、布農族打耳祭、達悟族飛魚祭與敬畏自然精神。
2. **漢人守護神與廟宇站**：媽祖（海上守護神）、土地公（守護田頭田尾）、飛簷燕尾脊與廟宇工藝。
3. **迎神賽會與陣頭文化站**：千里眼順風耳大仙尪仔、宋江陣保衛鄉里歷史與醒獅跳樁。
4. **現代環保誠心祭祀站**：雙手合十心香、減香減燒、電子鞭炮與「以米代金」助弱勢。

### 島群 2：家鄉老街島（第三單元 第 2 課：家鄉的老街，第 5～8 關）
5. **河運渡口與老街起源站**：淡水、大稻埕、鹿港帆船碼頭與商號聚落興起。
6. **紅磚長條街屋全剖面站**：前店後住、亭仔腳（騎樓）遮雨防曬、天井採光通風與巴洛克山牆。
7. **三峽傳統藍染工坊站**：山區種植大菁、溪水漂洗、浸染與接觸空氣「氧化」變藍。
8. **老街轉型與文創保存站**：古蹟立面修繕如舊、三峽金牛角名產與在地文化導覽再生。

### 海上看門獸導覽：Hakaw Utux 泰雅祖靈彩虹橋
- **無島嶼巨型海面飄浮設計（`scale: 2.35`）**：如同前一地圖的海龜一樣直接飄浮於雙島正南方海面，由祥雲浮座與 4 圈擴散水波紋托起，立有紅白黑菱形紋「祖靈之眼」守護柱、橋頂泰雅頭目守護者與海面漂浮的傳統織布機，點擊即可開啟全島導覽與彩虹橋品德試煉。

## 🛠️ 技術規格與教材審查

- **3D 引擎**：Three.js (WebGL, OrbitControls, PCFSoftShadowMap)，純程序化 Low-Poly 幾何建模，零外部 3D 資產依賴。
- **課綱審查**：依據 `g4-curriculum-review` 三階漏斗審查規範執行自我檢測，100% 通過（詳見 `三階漏斗AI自我檢測審查報告.md`）。
- **自動化測試**：採用 Playwright Chromium Headless 執行 E2E 自動化測試，主控台錯誤與未處理異常數為 0。
