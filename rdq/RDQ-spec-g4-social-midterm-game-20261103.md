# RDQ 需求規格：四年級社會科期中沉浸式複習遊戲網頁（第 7 輪雙閉環極致完備版）

## 一句話任務
打造專為國小四年級學生設計的單一檔案純前端現代卡通扁平風沉浸式探索網頁遊戲，嚴格對齊康軒四上社會第一、二單元課本與學習專題，融合海線情境、男女雙角、全螢幕音量控制、3心三星評價、地貌剖面特徵配對、年代倒數時光機、原漢住屋器物考驗、階層圖分類、選項打亂、探險圖鑑、集章手冊、Boss戰、錯題筆記本、Canvas雙卡，並內建 Playwright E2E 自動遊玩測試與即時自癒修復閉環，通過三階漏斗審查。

## ✅ 已確認
- **教學對象與主角選取**：臺中市梧棲區中正國小四年級學童，開局自由選擇「男生小航」或「女生小晴」。（Ⅰ、Ⅲ-3）
- **美術視覺風格與視窗**：現代卡通扁平風（色彩明亮柔和、高對比圓角卡片、大字級，最符合國小四年級現代教育 App 體驗），支援一鍵切換全螢幕與 0~100% 音量微調拉桿。（Ⅲ-4、Ⅲ-5、Ⅲ-6）
- **頂部儀表列**：常駐頂部 Header（44px），即時顯示章節進度條、當前生命值 ❤❤❤、累計星星數 ⭐。（Ⅲ-5）
- **關卡進程架構與難度**：**嚴格依序線性闖關**（不設跳關後門，維持完整挑戰性：序章梧棲 ➔ 現代三大重點 ➔ 年代倒數時光機 ➔ 原住民聚落 ➔ 漢人三合院 ➔ 小探究家階層圖 ➔ 期中 Boss 大會考 ➔ 錯題筆記本與終章頒發雙卡）。（Ⅲ-2、Ⅲ-3、Ⅲ-5、Ⅲ-6）
- **容錯與激勵評級機制**：每關 **3 顆愛心生命值 ❤**，通關時依剩餘生命值給予 **1～3 顆星星評價 ⭐⭐⭐**，扣完生命值需重新挑戰本小關。（Ⅲ-2、Ⅲ-4）
- **核心互動形式**：混合式深度互動（情境對話 ＋ 地圖四要素尋寶 ＋ 五大地貌剖面特徵配對 ＋ 傳統住屋局部探密 ＋ 器具古今對照與柴灰物盡其用情境題 ＋ 課本 P.48-51 器物材料/用途階層圖分類）。（Ⅲ-2、Ⅲ-3、Ⅲ-4、Ⅲ-6）
- **題目呈現細節**：題目選項**隨機打亂**，比例尺著重在**縮小倍率之工具概念辨識**（不作複雜公尺計算）。（Ⅲ-4、Ⅲ-5）
- **時光機過場效果**：**年代倒數計時時空穿梭儀**（從 2026 現代 ➔ 倒數至 100 年前漢人農村 ➔ 數百年前原住民族聚落），搭配 Web Audio 穿梭加速音效。（Ⅲ-5）
- **自動遊玩測試與即時自癒修復閉環（Playwright E2E Self-Healing Loop）**：（Ⅲ-7）
  - 採用 **Playwright 自動化無頭瀏覽器** 執行真實學生視角的 E2E 完整通關實測。
  - **自動修復門禁**：檢測出任何 Console Error、Unhandled Exception、按鈕卡死或狀態中斷，**立即原地自動修改代碼並重新回歸測試，直到 0 錯誤、100% PERFECT PASS**。
  - **成果與截圖**：產出專屬「自動遊玩測試驗證報告」，並留存各關卡自動運行截圖（首頁、地貌配對、時光機、原住民部落、三合院、階層圖、Boss戰、獎狀）。
  - **學童壓力與多載具測試**：模擬四年級學生快速連點/隨機點擊背景之防崩潰壓力測試，並執行 iPad (1024x768)、Chromebook (1366x768)、高解析桌面 (1920x1080) 多解析度適配檢驗。
- **教材單元具體設計（100% 康軒課本與學習專題）**：（Ⅰ、Ⅲ-3、Ⅲ-4、Ⅲ-5、Ⅲ-6）
  - **第一單元（現代家鄉探索）**：
    1. 地圖四要素：圖名、圖例、方向標、比例尺概念（縮小比例的工具）。
    2. 五大地形剖面與特徵配對：山地（海拔1000m以上、起伏大）、丘陵（海拔1000m以下、起伏較緩）、臺地（上方平坦、邊緣陡峭）、盆地（四周高、中間低平）、平原（地勢平坦開闊、海拔低）。
    3. 氣候與水資源：氣溫降雨、降水時空分佈（北部全年有雨、中南部乾濕季分明）、水資源（河川、水庫、地下水、埤塘）、枯水期乾旱與生活節水行動（關水龍頭、除濕機/冷氣水澆花沖馬桶、洗米水澆菜）。
  - **第二單元（時光機順序穿越）**：
    1. 原住民站：傳統住屋（排灣/魯凱石板屋【會呼吸、冬暖夏涼、防蟲】、達悟地下屋【避強風抗颱、冬暖夏涼】、泰雅木竹屋【就地取材、通風防潮】）＋ 傳統器物（木臼木杵【搗小米】、竹編魚筌【放溪流捕魚】、排灣陶壺【百步蛇紋/貴族象徵】、阿美陶鍋、排灣連杯【同心修好】、檳榔葉鞘食器【盛物】）。
    2. 漢人站：傳統住屋（竹管仔厝【竹泥稻草】、土埆厝【土埆磚冬暖夏涼】、三合院格局配置【正身神明祖先、左尊右卑護龍、大埕曬穀、大灶廚房、防風竹林】）＋ 傳統器物與巧思（紅磚大灶↔瓦斯爐、木製菜櫥↔冰箱、木柴灰燼悶地瓜與菜園肥料【物盡其用】、斗笠桌罩、藤編背簍 ＋ 現代海廢寶特瓶反思與自備餐具減塑）。
    3. 學習專題（小探究家）：融入課本 P.48-51 階層圖策略，引導學生依「製作材料（竹木、陶土、金屬、植物編織）」與「生活用途（飲食盛裝、捕撈耕作、住屋建造）」進行階層思維分類。
- **審查機制**：執行 `g4-curriculum-review` 三階漏斗自我檢測審查，進行至少 3 輪嚴格迭代，文末隨附審查報告。（Ⅰ）

## ➕ 已採納（象限Ⅳ）

- **錯題筆記本（診斷訂正）**：通關結算時條列本次答錯扣心的題目、迷思診斷與康軒課本對照頁碼。
- **一鍵清除重玩／換人闖關（Reset）**：首頁與結算頁提供防呆重置按鈕。
- **音量微調拉桿（0%~100%）**：提供滑動音量條與一鍵靜音。
- **終章雙成果卡匯出（Canvas 繪圖）**：專屬結業通關獎狀 ＋ 守護者成果卡。
- **全螢幕沉浸切換按鈕**：一鍵進出全螢幕。
- **頂部常駐儀表列**：即時顯示進度、心數、星數。
- **家鄉探險辭典／小圖鑑**：主畫面可打開隨時查看已收集解鎖的課本名詞圖解。
- **家鄉探險集章手冊**：通過各關獲得專屬徽章。
- **最終期中魔王大挑戰（Boss 戰）**：5 題精選四上社會期中真題對決。
- **Web Audio 純程式合成 8-bit 背景音樂與音效**：輕快晶片風背景旋律及各類音效。
- **四年級常見迷思解惑彩蛋**：針對「臺地 vs 丘陵辨析」、「地下屋避風抗颱原理」、「石板屋會呼吸特點」設計專屬誤區提示標籤。
- **LocalStorage 自動暫存進度**：防學生誤觸重整或關閉分頁，可隨時續玩。
- **教師審查與教材對照工作台面板**：畫面角落設有專屬按鈕，隨時可展開查看康軒課本頁碼、課綱指標與三階審查狀態。

## ❌ 排除項（明確不做）
- **排除教師一鍵跳關後門**：嚴格落實順序通關，維持完整的教學檢測效力。
- **排除非教材自創器物與民俗**：不加入課本未出現的手搖風鼓機、雙扇石磨、泰雅防鼠板等外部非標內容。
- **排除複雜外連伺服器或多人連線**：無需帳號登入、無後端伺服器延遲，確保班級平板即開即玩。
- **排除語音朗讀合成（Web Speech API）**：因各平板語音庫相容度不一，改以精簡題幹與大字體圖文呈現，降低學生閱讀干擾。

## 📋 一段式需求規格
為**臺中市梧棲區中正國小四年級**學童打造一款**單一檔案純前端（HTML5/CSS3/JS）**之**現代卡通扁平風沉浸式社會期中複習探索網頁遊戲**。遊戲嚴格鎖定本機雲端硬碟 **`115四上教材/115四上社會課習` 之康軒版四上社會課本與學習專題**，嚴禁任何非教材自創內容。開局可選**男生小航**或**女生小晴**，介面配備**全螢幕切換**、**音量微調拉桿**、**換人清除重置**與**頂部常駐儀表列（進度/血量❤❤❤/星星⭐）**，採**無跳關嚴格順序闖關**與**每關 3 顆愛心搭配三星評價**機制；題目選項具備**隨機打亂**功能以確保理解。第一部以**臺中海線**為起點，解鎖**地圖四要素（比例尺概念辨識）**、**五大地形剖面與特徵標籤配對**及**氣候水資源（乾濕季與生活節水）**；通關後啟動**年代倒數時光機**進入第二部，順序探訪**原住民族（排灣魯凱石板屋、達悟地下屋、泰雅木竹屋；木臼杵、魚筌、陶壺陶鍋、連杯、葉鞘）**、**漢人傳統住屋及器具（竹管仔厝、土埆厝、三合院格局配置；紅磚大灶、柴灰再利用、菜櫥、斗笠桌罩、減塑生活）**與**課本 P.48-51 小探究家階層圖分類挑戰**。通關後迎接**最終期中魔王大挑戰（5題真題 Boss 戰）**，產生**錯題筆記本**、**家鄉探險集章手冊**、**家鄉辭典圖鑑**與**Canvas 專屬姓名獎狀與個人成果卡**。具備 **Web Audio 8-bit 背景音樂與音效**、**迷思解惑彩蛋**、**LocalStorage 自動進度存檔**、**教師教材出處抽屜面板**。開發完成後自動執行 **Playwright E2E 自動化遊玩測試（含 iPad/Chromebook 多載具適配、學童手速連點壓力測試與截圖證據）**，遇任何問題**即刻原地修復重測直到 0 錯誤**，並落實 **`g4-curriculum-review` 三階漏斗自我檢測審查（至少3輪）**。
